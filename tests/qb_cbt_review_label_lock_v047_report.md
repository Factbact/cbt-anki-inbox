# v0.4.7 不具合再現・回帰テスト報告

実施日: 2026-10-25

## 対象

- 旧版 Git blob: `0fb781f958ed625112ac08011956f53e73e794da`（v0.4.6）
- 配布版 Git blob: `5e5d4c700d786cda39656122343a81689ce75d4e`（v0.4.7）
- ローカルで検証した版: `c6f19c463ca363cca3c461e24285e0fda1ad934d`。配布版との差分はファイル末尾の改行1文字のみであり、コード本文は一致。

## 環境と方法

Python Playwright + Chromium。about:blank上に合成したQB形式のDOMを作成し、URL・localStorage・fetchをローカルで置き換えて検証した。ユーザーの実アカウントの成績・履歴を操作していない。ブラウザから現在のログイン済みQBページを取得できなかったため、これは本番環境の結合テストではない。

旧版では、正誤表示の後に履歴表を1500ms遅延して表示すると、履歴を待たず「前回評価不明」で終了した。同じ条件で修正版が前回△を読んで△へ変更することを確認した。

## 結果

旧版不具合の再現1ケース + 修正版20ケース、計21ケースが期待どおり。

| ケース | 結果 |
| --- | --- |
| 旧版の履歴表示前の早期停止を再現 | 再現成功 |
| 結果表示より後に履歴が表示される | 修正版で△への変更成功 |
| 前回△がSVGのみ、結果の正誤文字なし | 成功 |
| 前回×・今回正解 | △への変更成功 |
| 不正解なのに「正解：b」が表示される | 正解と誤認せず×を維持 |
| 前回○がSVG path | ○を維持 |
| 手動◎・今回正解 | ◎を復元 |
| 履歴表が解答前にしか存在しない | 解答前に取得して成功 |
| 遅延描画・UUIDをキーとするReact履歴 | 読み取り成功 |
| 同一問題を再演習 | 古いスナップショットを使わず、同日重複加算なし |
| 手動○の後に同一問題を再演習 | 以前の△を再利用しない |
| 履歴の読み込み中に手動で◎へ変更 | 手動操作を優先 |

| 端末内の古い○とQBの△が不一致 | QBの△を優先 |
| 状態遷移・日付・問題IDの検査 | 20個の内部assertionを通過 |
| 従来の△固定モード | 自動クリック成功 |
| ドラッグリサイズ・サイズ保存 | 維持 |
| 取り消し・自信なし | 操作と記録の更新成功 |

`node --check` で構文エラーなし。評価ルール本体 `decideSmart`、取り消し・自信なし、パネルのリサイズ関数は旧版から変更していないことも比較した。

## 未検証・制約

- 実際にログインしたQBの全DOMバリエーション、サーバーへの永続保存は未検証。
- 根拠がない前回評価は推測しない。12秒の待機後にも読めなければ自動変更を停止し、行数や読取状況を表示する。
- 3学習日の独自カウントはブラウザごとであり、端末間自動同期は追加していない。
- 手動登録が不要と検証できたのは上の既知ケースであり、あらゆる画面で一切不要になることを保証していない。
